# Performance Baseline Artifacts

**Status:** Future scope
**Owner:** `ADR-0042`

This directory is reserved for release-gate performance baseline artifacts such
as `baselines/v1.0.0.json`.

It is intentionally empty during the pre-skeleton documentation pass. Baseline
measurement files are populated only when the Phase 1 release-gate measurement
process exists and an ADR/release decision accepts the exact artifact.
